# FinSight – Credit Default Prediction & Financial Analytics Platform

## About the Project
FinSight is a Machine Learning-based financial analytics platform that predicts whether a customer is likely to default on credit payments.

## Features
- Credit Default Prediction
- Customer Financial Analysis
- Machine Learning Model
- Interactive User Interface
- Data Visualization

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Project Objective
To analyze customer financial information and predict credit default risk using machine learning algorithms.

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
streamlit run app.py
```
